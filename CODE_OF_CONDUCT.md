# Code of Conduct

Be useful, direct, and respectful.

This project follows the Contributor Covenant Code of Conduct, version 2.1:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Expected Behavior

- Assume good intent, but value clear evidence over vibes.
- Give actionable feedback.
- Keep discussions focused on the work.
- Be especially careful with security reports and private data.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information or secrets.
- Dismissing security/privacy concerns without investigation.
- Repeatedly derailing technical discussion.

## Enforcement

Maintainers may remove comments, close issues, block participants, or otherwise limit access when behavior harms the project or its contributors.
