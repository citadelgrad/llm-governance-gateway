# Usage Log is a new proxy-owned table, separate from audit_log

The usage dashboard needs per-request tokens, cost, and the real API key. `audit_log` already records one row per request with `tenant_id` and `model_id`, so reusing it looked tempting. We rejected that: `audit_log` is governance-owned, append-only, and deliberately stores a pseudonymized `user_id` for compliance — it never carries token counts or cost, and identifying the real API key there would undermine the pseudonymization it exists for. Token/cost data also only exists after the provider responds, which happens entirely inside the proxy's request lifecycle, after governance's `/inspect` call has already returned. We're instead adding a new `usage_log` table, owned and written by the proxy, as an independent record of the same request for a different purpose (cost/observability, not compliance).
